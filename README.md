# mandapos
Free and OpenSource Mandatech POS System

# Target
UMKM di Indonesia. Oleh karena itu, UI/UX harus sangat mudah dan mempunyai learning curve yang sangat pendek

# Stack
* Laravel
* Deploy di Railway
* SQLite untuk offline access, and ketika online, upload ke Postgre

# Features
* Track cash in dan out dari drawer
* Track clock in/out pegawai
* Simpan dan edit order tanpa pembayaran
* Kirim order ke layar dapur sesuai urutan pesanan
* Tampilkan informasi order ke layar customer
* Kategorikan order sebagai dine in, takeaway dan delivery
* Notifikasi email untuk low stok
* Negative stock alert
* Memungkinkan generate dan scan barcode dengan embedded weight
* Items
* Categories
* Discounts
* Inventory Management
* Employees
* Customers
* Setting layout dan informasi nota pembelian
* Multi-store
* Laporan: sales summary, sales by item, sales by category, sales by employee, sales by payment type, receipts, sales by modifier, discounts, taxes, shifts
